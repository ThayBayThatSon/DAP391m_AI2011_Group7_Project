# Comparative US AQI Time Series Forecasting in California with Extreme-Event and Climate-Context Evaluation

This repository contains the data, modeling pipeline, and LaTeX manuscript for evaluating machine learning models on US Air Quality Index (AQI) forecasting in California (Fresno, Los Angeles, and San Jose).

## Abstract

This project presents a rigorous hourly US AQI forecasting benchmark in California using a merged panel dataset of 181,122 observations from 2018–2025. The panel combines U.S. EPA Air Quality System observations and Open-Meteo supplemental records. Five tabular regressors (Linear Ridge, Random Forest, LightGBM, CatBoost, and XGBoost) are evaluated alongside two naive baselines (Persistence and Climatology). 

The experimental design adopts a climate-context-aware temporal split:
- **Train**: 2018, 2019, 2021-2024
- **Validation**: 2020 (Extreme-AQI / Wildfire-context Holdout)
- **Test**: 2025 (Independent Test Year)

Two operational configurations are assessed:
1. **Short-term Nowcasting (Lag 1-3h)**: Autoregressive setting where recent AQI lags are available.
2. **Long-term Forecasting (Lag 24h)**: Strict 24-hour-ahead forecasting that masks local AQI information from $t-1$ to $t-23$.

## Directory Structure

- `app/`: Source code for the Streamlit application and APIs.
- `data/`: Datasets and generated plots.
  - `data/processed/`: Cleaned and merged CSVs (leaderboard, ablation, audit, scenarios).
  - `data/plots/`: Figures and graphics generated by the pipeline for the paper.
- `docs/`: Relevant feedback documents and weekly reports.
- `models/`: Serialized models (Joblib, JSON, CBM, TXT) generated during training.
- `notebook/`: Jupyter Notebooks used for exploratory data analysis (EDA) and model reporting.
- `scr/`: Python source code scripts for data collection, preparation, and modeling.
- `main.tex`: The main LaTeX manuscript of the paper.
- `SUBMISSION_CHECKLIST.md`: Checklist outlining the project's source of truth and files submitted.

## Setup & Installation

It is recommended to use a Python virtual environment to install dependencies.

```bash
# Create and activate a virtual environment
python -m venv .venv
# Windows
.venv\Scripts\activate
# Linux/Mac
source .venv/bin/activate

# Install requirements
pip install -r requirements.txt
```

## Reproducibility 

The entire modeling pipeline—from training models and generating leaderboard metrics, to feature ablation, scenario evaluation, leakage auditing, and figure plotting—is automated via a single driver script.

To reproduce the benchmark outputs and plots, run:
```bash
python scr/run_all.py
```

## Key Results

1. **Short-term Nowcasting**: LightGBM achieves the highest $R^2$ (0.8695). However, the simple **Persistence** baseline outperforms complex models during Extreme AQI ($>95$th percentile) and Wildfire season windows, highlighting the sheer strength of short-term autocorrelation during anomalies.
2. **Long-term Forecasting**: XGBoost slightly edges out competitors with an $R^2$ of 0.4611, while the naive baselines completely collapse, demonstrating that a 24-hour horizon requires the models to genuinely learn the meteorological climate context and spatial dynamics rather than copying previous values.

## Notes & Limitations

- The dataset relies on a PM2.5-derived proxy for the target AQI.
- Due to AQS reporting latency, the 2025 Test year is heavily reliant on Open-Meteo supplementary data, presenting an out-of-distribution challenge.
